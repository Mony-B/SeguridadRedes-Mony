Al revisar el archivo descargado, vemos que está comprimido mil veces (un archivo dentro de otro, del 1000 al 1). Para no estar extrayendo uno por uno a mano, corremos este script rápido:

```
for i in {1000..1}; do tar -xvf "$i.tar"; done
```

Ya que termine, nada más abrimos la imagen y listo, ahí está la flag:

```
open flag.png
```
